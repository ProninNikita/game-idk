# Project Hearthline

Рабочее название: **Project Hearthline**.

Жанр: top-down survival automation sandbox. Игра берет настроение одиночного выживания, радость быстрого сбора и расширения базы, а также удовольствие от построения производственных цепочек, но не должна быть клоном конкретных игр. Главная идея: игрок выживает в живом мире, строит лагерь, автоматизирует добычу и производство, исследует биомы и удерживает систему от распада.

## Текущий технический выбор

- Движок: Godot.
- Рекомендованная ветка для старта: **Godot 4.6.x stable**.
- По официальному архиву Godot актуальная стабильная версия на 18 мая 2026: **Godot 4.6.2-stable**.
- Локально сейчас установлен Godot: **4.3.stable.official**.
- Вид: 2D top-down.
- Язык прототипа: GDScript.

## Ближайшая цель

Собрать вертикальный прототип на одной небольшой карте:

- игрок двигается, собирает ресурсы и выживает;
- есть базовое строительство;
- есть 1-2 автоматизируемые цепочки;
- есть день/ночь и хотя бы одна угроза;
- состояние мира сохраняется и загружается.
